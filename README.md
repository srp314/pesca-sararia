# Pesca en Sararia: prueba abierta

Prototipo jugable del lance de pesca de **Sararia**, un juego en desarrollo. Se juega en el navegador:

**https://srp314.github.io/pesca-sararia/**

## Cómo se juega

1. **Lanzar.** Click derecho carga la caña y otro click la suelta: cuanto más cargás, más lejos. El mouse apunta.
2. **Esperar.** Con «Pez cerca», no tires o tirá suave. Si la boya baja apenas, está picando: todavía no.
3. **Clavar.** Cuando la boya se hunde entera, click izquierdo y subí el mouse de golpe.
4. **Pelear.** Con flecha, el pez corre: click izquierdo y tirá el mouse para el lado contrario. Sin flecha, descansa: mantené click derecho para cobrar. Barra roja: mantené Q para soltar tensión.

## Qué se mide

La prueba anota cómo se juega (lances, piques, peleas, tiempos y la opinión del final) sin datos personales, para ajustar el juego.

Este repositorio sólo contiene la versión publicada. La fuente vive en el proyecto del juego.
